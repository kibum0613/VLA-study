# π₀ 아키텍처와 LIBERO-Plus 평가

## 1. 모델 개요

π₀는 VLM과 별도의 **Action Expert**를 결합하고, **flow matching**을 이용해 연속적인 action chunk를 생성하는 VLA 계열 모델입니다.

```text
이미지 + 언어 + 로봇 상태
          ↓
       VLM Backbone
          ↓
      Action Expert
          ↓
     Flow Matching
          ↓
 Continuous Action Chunk
```

NORA처럼 action을 이산 token으로 autoregressive하게 생성하는 방식과 달리, π₀는 연속 action trajectory를 생성하는 방향에 가깝습니다.

## 2. Flow Matching을 직관적으로 이해하기

Flow matching은 처음부터 정답 action을 한 번에 분류하거나 token으로 선택하는 것이 아니라, **noise 상태에서 실제 action trajectory 방향으로 이동하는 vector field를 학습**합니다.

학습 과정의 직관은 다음과 같습니다.

```text
Noise Action
    ↓
중간 상태에서 어느 방향으로 이동해야 하는지 학습
    ↓
점차 실제 demonstration action 분포로 이동
    ↓
Continuous Action Chunk
```

따라서 로봇의 여러 관절·end-effector 움직임 사이의 연속성을 표현하기에 적합한 구조입니다.

## 5. 구조적 해석

### NORA 대비 장점
NORA는 action을 이산 token으로 압축한 뒤 autoregressive하게 생성합니다. 반면 π₀는 flow matching으로 연속 action chunk를 생성합니다.

이 구조는 다음 측면에서 로봇 제어에 유리할 가능성이 있습니다.

- 연속적인 trajectory 표현
- 여러 action dimension 사이의 상관관계 모델링
- 정밀한 continuous control

실험에서도 Object와 LIBERO-10에서 NORA보다 높은 성능을 보였습니다.

### 여전히 남는 한계
π₀도 기본적으로 현재 관측을 바탕으로 다음 action chunk를 생성합니다.

따라서 다음과 같은 정보가 명시적으로 누적되는 구조는 제한적입니다.

- 이전 action이 실제로 성공했는지
- execution error가 얼마나 누적됐는지
- task가 현재 어느 단계까지 진행됐는지
- 실패 후 어떤 recovery가 필요한지

LIBERO-Goal과 긴 horizon task에서 성능이 상대적으로 낮은 결과는 이러한 **task progress tracking / closed-loop recovery** 문제와 연결해 볼 수 있습니다.

다만 이 부분은 결과를 바탕으로 한 연구적 해석이며 추가 실험이 필요합니다.

## 6. 현재까지의 결론

직접 평가한 네 모델의 전체 성능은 다음과 같습니다.

```text
OpenVLA-OFT+  80.96%
OpenVLA-OFT   71.20%
π₀            46.49%
NORA          39.49%
```

현재 연구 baseline으로는 OpenVLA-OFT 계열이 높은 성능과 구현 안정성을 보였고, π₀는 **flow-matching 기반 continuous action generation을 비교하기 위한 중요한 비교군**으로 볼 수 있습니다.
