# π₀ 아키텍처와 LIBERO-Plus 평가

## 1. 모델 개요

- π₀는 VLM과 별도의 **Action Expert**를 결합하고 **flow matching**으로 연속 action chunk를 생성하는 VLA 계열 모델임.

```text
이미지 + 언어 + 로봇 상태
          ↓
       VLM Backbone
          ↓
      Action Expert
          ↓
     Flow Matching
          ↓
 Continuous Action Chunk
```

- NORA처럼 action을 이산 token으로 autoregressive하게 생성하는 방식과 다름.
- 연속 action trajectory 자체를 생성하는 방향에 가까움.

## 2. Flow Matching 직관

- 정답 action을 분류하거나 token으로 선택하는 방식이 아님.
- noise 상태에서 실제 action trajectory 방향으로 이동하도록 vector field를 학습함.

```text
Noise Action
    ↓
중간 상태에서 이동 방향 학습
    ↓
실제 demonstration action 분포로 이동
    ↓
Continuous Action Chunk
```

- 여러 관절과 end-effector 움직임 사이의 연속성을 표현하기에 적합한 구조임.

## 3. LIBERO-Plus 전체 평가

## 5. 구조적 해석

### NORA 대비 차이

- NORA는 action을 이산 token으로 압축한 뒤 autoregressive하게 생성함.
- π₀는 flow matching으로 연속 action chunk를 생성함.
- 연속 trajectory 표현, action dimension 사이의 상관관계, 정밀 제어 측면에서 구조적 차이가 있음.
- Object와 LIBERO-10에서 NORA보다 높은 결과가 확인됨.

### 남는 한계

- π₀도 현재 관측을 기준으로 다음 action chunk를 생성하는 구조임.
- 다음 정보가 명시적으로 누적되는 구조는 제한적임.
  - 이전 action의 실제 성공 여부
  - 실행 오차 누적량
  - 현재 task progress
  - 실패 이후 recovery 상태
- Goal과 긴 horizon task에서 상대적으로 낮은 결과가 나타남.
- 이 결과를 task progress tracking이나 closed-loop recovery 문제와 연결해 볼 수 있으나 추가 검증이 필요함.

- π₀는 flow-matching 기반 continuous action generation을 비교하기 위한 중요한 비교군임.

## 7. 다음 분석 과제

- π₀ perturbation category별 결과 분석 필요함.

- Mobile manipulation 및 cross-embodiment 확장 가능성 검토 필요함.
